          05 · Method

          How this works, and where it does not

          Built

          • KB built with the ITU reference ingestion code (parser, chunker, metadata, ChromaDB KnowledgeBase), article-level chunks for laws.
          • Scenario engine releases events per role with delays. The Service Owner only learns about personal data through the Data Protection role.
          • Typed protocol: INFORM · REQUEST · ASSESS · PROPOSE · OBJECT · DECIDE. Only the human may DECIDE.
          • Citation verifier: SUPPORTED, WEAK, UNCITED or INVALID for every claim.
          • Append-only JSONL audit, SHA-256 chained, re-verified in your browser.

          Limits

          • Agents follow hand-written playbooks. Retrieval picks the cited sources, but the claim wording is a template. No LLM reasoning is shown.
          • "Reasoning trace" means facts, rule, retrieval and choice. It is not a model's hidden chain of thought.
          • The KB is incomplete: NIAF, the National Cloud Security Policy and NCEMA 7000 are not in it.
          • English translations only. The Arabic legal text prevails.
          • The eval queries were written by the author, so the scores are optimistic.
